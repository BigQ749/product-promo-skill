# 产品宣传片 skill

仓库 slug：`product-promo-skill`（GitHub 仓库名不支持纯中文 slug；本 skill 中文名即为「产品宣传片」。）

可复用的 **APP / SaaS / 产品宣传片** 出片流程（代码原生画面，非抽卡生成视频）。

## 怎么用

1. 把本仓库的 `SKILL.md` 放进你的 Agent / Claude Code skills 目录，或直接把全文贴给助手。
2. 说「按产品宣传片 skill 做 XXX 的宣传片」，助手会按 brief → 真实 UI → 节拍网格 → 分镜确认 → 风格帧 → 出片 → 双轮评审执行。
